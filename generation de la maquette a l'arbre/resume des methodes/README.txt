
# Présentation Beamer — De la maquette à une représentation hiérarchique

## Fichiers
- `main.tex` : présentation LaTeX Beamer complète.
- `README.txt` : instructions de compilation.

## Compilation dans VS Code
Installer une distribution LaTeX (MiKTeX ou TeX Live) et l'extension
LaTeX Workshop.

Puis ouvrir `main.tex` et utiliser :
- `Ctrl + Alt + B` pour compiler ;
- `Ctrl + Alt + V` pour ouvrir le PDF.

La présentation ne dépend pas d'images externes : les schémas sont dessinés
avec TikZ afin de rester simples et lisibles. Les cinq articles fournis ont
servi de base au contenu.

## Remarque scientifique
La présentation distingue volontairement :
- les arbres de composants/layout ;
- l'arbre de subdivisions de DCGen ;
- la spécification de layout et les arbres de ReverseORC.

Ils ne représentent pas exactement le même niveau d'information.
